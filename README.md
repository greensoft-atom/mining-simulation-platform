# Deepforge: Mining Kingdoms (working title)

An ad-free mining RPG for Android: tactical turn-based delves, an idle homestead, lucky finds with published odds, and asynchronous guild play, built on a server-authoritative backend.

- **[`docs/`](docs/README.md)** is the full development documentation: vision, game design, economy, requirements, architecture, API, data model, client, simulation core, security, operations, legal and plan, plus verified reference code and models.
- **[`study/`](study/)** holds the original design study and competitor research the docs are based on.
